# team-pug-patrol
# Конвейер обработки документов

Сервис предназначен для автоматизированной обработки документов различных форматов. Пользователь загружает документ и выбирает необходимые операции: извлечение текста, анализ статистики или преобразование в другой формат.

## Назначение проекта

Основная задача сервиса — упростить работу с документами и объединить несколько операций по их обработке в одной системе.

Вместо ручного выполнения каждой операции пользователь может отправить документ на обработку и получить результат после завершения задания. Это позволяет сократить время работы с документами и упростить выполнение повторяющихся задач.

## Целевая аудитория

Система ориентирована на:
- Студентов и преподавателей, которым необходимо обрабатывать учебные и текстовые материалы.
- Сотрудников организаций, работающих с большим количеством документов.

## Основные возможности

В рамках проекта предполагается реализация следующих функций:

- **Загрузка документов** — приём файлов для последующей обработки, максимальный размер — 50 МБ.
- **Извлечение текста** — получение текстового содержимого документа.
- **Подсчёт статистики** — определение характеристик документа, например количества слов, символов и страниц (если применимо).
- **Конвертация форматов** — преобразование документов из одного поддерживаемого формата в другой: pdf, txt, docx, json, xml, csv.
- **Управление заданиями (Job)** — создание заданий, отслеживание их выполнения и получение результатов.
- **Обработка ошибок** — фиксация ошибок при некорректных файлах или сбоях отдельных операций.
- **Взаимодействие с внешними сервисами** — возможность подключения инструментов распознавания текста (OCR) или перевода документов.(в следующем семестре)

## Жизненный цикл задания

Каждый документ, отправленный на обработку, проходит определённые этапы:

1. **Загружен** — документ принят системой.
2. **В обработке** — выполняются запрошенные операции.
3. **Обработан** — все операции успешно завершены.
4. **Отклонён** — обработка не может быть выполнена из-за ошибки или несоответствия требованиям.

## Ограничения проекта

В рамках текущей версии проекта не предусматриваются:
- Создание и редактирование содержимого документов вручную.
- Интеллектуальная суммаризация и классификация документов с использованием LLM.
- Регистрация и авторизация пользователей.
